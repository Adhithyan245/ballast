A reliability check for AI research assistants

Before an AI's answer reaches a scientist, make sure it holds steady.

Ballast asks the model the same question again, checks every quote against the source paper, and pushes back once. Answers that waver go back to a person instead of into the lab notebook.

How it was tested

Preregistered before a single main-study call

100expert-labeled questions from PubMedQA (yes / no / maybe), each with its source abstract
5model families: Claude, Gemini, gpt-oss, Qwen, and DeepSeek (exploratory)
8,998recorded answers, every one cached and published; no LLM judge in any metric
108automated tests; one command regenerates every number and chart
  • Not a medical evaluation. Accuracy means agreement with PubMedQA's expert labels.
  • Claude and DeepSeek ran through agent tools (Claude Code, Kiro), which add context and fix the temperature.
  • 100 questions and one pushback wording: intervals are wide, about ±10 points.
  • The quote check confirms a quote exists in the abstract, not that it supports the answer.
  • At equal coverage, the pushback check beat agreement alone only for Claude; for the other models the gain mostly came from answering fewer questions.
  • Models were tested between 30 Oct and 5 Nov 2026; hosted models can change behind the same name.
